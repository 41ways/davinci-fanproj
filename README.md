# 다빈치코드

숫자는 가려지고 색만 보입니다. 순서를 읽어 상대의 숫자를 맞히는 온라인 다빈치코드입니다.

![타이틀](assets/screenshots/title.png)

## 플레이

https://davinci.41ways.workers.dev/

2~4인. 방 코드나 초대 링크로 붙고, 봇으로 채우면 혼자서도 연습할 수 있습니다. 계정은 없습니다.

## 규칙

타일 26장(검정·흰색 0~11, 조커 둘)을 나눠 갖고 손패는 작은 수부터 순서대로 놓습니다. 색은 뒷면에서도 보이고 숫자만 가려집니다. 자기 차례에 바닥에서 한 장 집고, 상대의 덮인 타일 하나를 지목해 값을 부릅니다. 맞히면 공개하고 한 번 더 맞힐지 고를 수 있고, 틀리면 집은 타일을 공개해 손패에 넣고 차례가 끝납니다. 자기 타일이 전부 공개되면 탈락, 마지막까지 남으면 승리입니다.

조커는 숫자가 없어서 손패 어디에나 놓을 수 있는데, 누가 조커를 들고 있는지 티가 안 나도록 시작 손패를 고르는 단계와 타일을 놓는 동작을 모두에게 똑같이 보여줍니다.

혼자 연습(봇과)은 서버 없이 브라우저에서 돌아가고, 온라인 대전은 서버(Cloudflare Workers + Durable Object)가 판정을 맡습니다.

## 기술

정적 화면(`public/`)은 Cloudflare Workers 자산으로, 소켓과 상태 확인만 Durable Object 하나로 처리합니다. 로컬 개발은 Node(`server.js`)로 같은 `game.js`를 띄웁니다. 규칙 엔진(`rules.js`)과 봇(`ai.js`)은 순수 함수라 서버와 화면이 같이 쓰고, 화면 쪽은 심볼릭 링크로 원본을 그대로 참조합니다.

```bash
npm install
npm start        # http://localhost:8876
npm test         # 규칙 · 봇 · 서버 시나리오 테스트
```

배포:

```bash
./bump.sh              # 자산 캐시 무효화
npx wrangler deploy
```

## 알려진 제약

관전 모드가 없고, 판에서 빠지면 다시 들어올 수 없습니다. 무를 수도 없습니다. 방은 서버 메모리에만 있어서 배포하면 열린 방이 사라집니다.
